# More nodes per city, upgraded in different ways

- **What:** A city can own several nodes, and nodes upgrade along different paths, not one level track each.
- **Why:** The user (2026-10-11): the garrison's nodes panel "indicates that the capitol can only hold a gold mine and
  that only 1 node is available for the capitol. However, that's not intended to be the case, that's just part of this
  test map [...] We should be able to have more nodes, and they should be upgradable in different ways." The rules
  already let the nearest city own any number of nodes; the test map gives the Capitol one, and the interface shows
  only one well. The upgrade paths are design.
- **Done when:** The user has designed the upgrade paths and the city screen lists every node with its paths.
- **Who:** The user designs the paths; Claude builds the screen to hold many.
