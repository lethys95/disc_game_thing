# Brainstorm (Claude's proposals, not canon)

The user asked for creative proposals on biomes, nodes and items (2026-09-28): "nobody remembers an item that just gives +5 damage". Everything in this folder is **Claude's invention, offered for picking**. Nothing here is built or canon until the user takes it. Names are proposals too.

How to use it: mark an idea inline, in any way (✓, ✗, "maybe", a rewrite). Claude moves a taken idea into the design canon, with the user's version winning, and builds it when its milestone comes.

- `items.md`: about 40 items, grouped by the trick that makes each one memorable.
- `nodes.md`: city nodes, and levels that change what a node does instead of only raising its numbers.
- `biomes.md`: biomes that change a rule of the map or the battle, and decide which nodes, tribes and lairs appear.

Three principles, applied throughout:
1. **Every idea changes a decision**: where to stand, whom to hit, when to fight, which city to take, whom to elevate. An idea that only raises a number is marked as filler.
2. **No RNG** (pillars). "10% chance on hit" becomes a counter, a threshold, a charge, a position or a rhythm. That constraint helps: deterministic effects can be planned around, and planning is the fun here.
3. **Lean on what only this game has**: 3x3 grids and rows, initiative as a number of actions, flat armor against shields, the graveyard, leader elevation, fog and remembered sightings, typed mana, recruit marks ("where was this unit born").
